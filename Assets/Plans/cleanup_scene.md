# Обзор проекта
- Название игры: Interflow (Стратегия)
- Основная концепция: RTS-игра с юнитами, зданиями и ландшафтом на основе мешей.
- Игроки: Одиночная игра (судя по структуре сцены).
- Конвейер рендеринга (Render Pipeline): Встроенный (Built-in).
- Целевая платформа: ПК (StandaloneWindows64).

# Игровые механики
## Основной игровой цикл
Игра включает управление юнитами (Peasants, Riflemen, Footmen), строительство зданий (TownHall, Barracks, Towers) и сбор ресурсов (GoldMine).

# UI
В сцене присутствуют текстовые метки и маркеры (объект Texts).

# Ключевые ассеты и контекст
- Сцена: `Assets/StrategyCore/Scenes/interflow.unity`
- Корень ландшафта: GameObject с именем "Terrain", содержащий несколько дочерних объектов с мешами.
- Модели: Здания, юниты и деревья, распределенные как корневые объекты или внутри контейнеров.

# Этапы реализации
## 1. Удаление моделей (Здания, Деревья и Юниты)
- Найти и удалить следующие корневые игровые объекты и их дочерние элементы:
    - Здания: `GoldMine`, `TownHall`, `Althar`, `Blacksmith`, `Farm`, `Barracks`, `CityBuilding`, а также все типы башен (`BaseTower`, `ArrowTower`, `CannonTower`, `MagicTower`).
    - Деревья: `TreeHolder`, `TreeHolder (2)` и все их содержимое.
    - Юниты: Все объекты `Peasant`, `Rifleman`, `Footman`, `Arthas`, `MountainKing`, а также транспорт (`Ship`, `Zeppelin`).
    - Прочее: `ItemDroppedChest` (сундуки с предметами).
- Для удаления будет использован скрипт, чтобы гарантированно найти все экземпляры.

## 2. Выравнивание ландшафта
- Целевые объекты находятся внутри "Terrain": `Cliffs`, `Ground`, `ShallowWater`, `WaterCliffs`, `Water`, `WaterVisuals`.
- Для каждого из этих объектов:
    - Получить `MeshFilter` и его меш (`mesh`).
    - Создать уникальный экземпляр меша, чтобы не изменять исходный файл ассета.
    - Изменить массив вершин (`vertices`): установить координату `y` каждой вершины в `0` (в локальном пространстве).
    - Обновить меш с помощью `mesh.vertices = modifiedVertices` и `mesh.RecalculateBounds()`.
    - Если у объекта есть `MeshCollider`, обновить его, чтобы он соответствовал выровненному мешу.
- Примечание: Если выравнивание подразумевает удаление перепадов высот, меши скал (`Cliffs`) станут плоскими на уровне земли.

# Проверка и тестирование
- Визуальный осмотр сцены в редакторе Unity.
- Проверка отсутствия юнитов, зданий и деревьев в иерархии.
- Проверка того, что все меши ландшафта стали плоскими на высоте Y=0.
- Отсутствие ошибок в консоли после выполнения действий.
